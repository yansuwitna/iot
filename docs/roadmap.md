# Development Roadmap

- **Fase 0 - Analisis**: Planning, architecture design, folder setup.
- **Fase 1 - Foundation**: Backend/Frontend bootstrap, DB setup, basic CI/CD & Docker.
- **Fase 2 - Authentication**: Auth, multi-tenancy context, RBAC, audit logs.
- **Fase 3 - Project Engine**: Project management, templates, component registry.
- **Fase 4 - Code Generator**: Code generation logic for ESP32/Arduino, pin validation.
- **Fase 5 - Device & Telemetry**: Device registration, REST telemetry endpoint, dashboard.
- **Fase 6 - Learning**: Class management, assignments, assessments, rubrics.
- **Fase 7 - White Label**: Branding configurations, custom domains.
- **Fase 8 - Backup & Production**: Automated backups, restore testing, deployment docs.
